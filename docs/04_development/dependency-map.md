## 并行开发依赖规则

- 前端泳道可在 `DEV-001` 后启动，不依赖全部后端业务完成；其最小前置依赖是 API 契约、统一错误结构、任务状态结构和基础权限边界。
- 每当后端修改 DTO、错误码、任务状态或分页结构时，必须同步更新前端 API client、mock/stub 和契约测试。
- `DEV-004` 至 `DEV-007` 期间，前端页面骨架按功能域分批接入对应服务，不等待所有后端模块一次性交付。
- `DEV-008` 只负责真实接口闭环和三角色 E2E 验收，不作为前端工作的起点。
- 当前协作方式采用多个 agent 人工编排；协调 agent 负责依赖冲突收敛，QA/契约 agent 负责联调差异清单。
