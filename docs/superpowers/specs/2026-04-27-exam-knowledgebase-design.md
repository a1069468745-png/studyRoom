## 1. 目标与范围

本次设计面向以下已确认需求：
1. 知识库支持图文，后续支持视频。
2. 系统支持 Web 客户端与管理端，明确老师/学生/管理员功能边界，并形成可人工验证文档。
3. 试卷支持从知识点生成，并可混合历史真题；按当前年级匹配，支持中考/高考混排，覆盖全年级知识点。
4. 出题随机规则支持规则定义器，支持可视化配置，支持按难度、知识点等多维度约束。
5. 考试支持答案；大题支持解题步骤或参考答案。
6. 视频解析采用“增强方案”：半自动生成 + 人工审核发布。

## 2. 端与角色规划

### 2.1 Web 客户端（老师与学生）

学生侧：
- 浏览知识库图文内容（按学段/年级/学科/章节/知识点）。
- 参加考试、查看答案与解析。
- 查看大题步骤化讲解与视频解析（审核通过后）。

老师侧：
- 维护教学可见的知识点映射关系。
- 发起组卷（知识点题 + 历史真题混排）。
- 使用规则定义器模板生成试卷。
- 查看考试结果、错题分布与知识点掌握度。

### 2.2 管理端（后台管理员）

管理员侧：
- 管理知识库内容（图文首发、视频资源预留与治理）。
- 审核题库与历史真题数据。
- 管理规则模板（发布、下线、版本控制）。
- 审核视频解析内容并发布。
- 维护基础字典（学段、年级、考试类型、难度、题型等）。

## 3. 功能设计

### 3.1 知识库（图文 -> 视频演进）

首版（M1）：
- 支持文本、图片、图文混排。
- 内容结构：学段 -> 年级 -> 学科 -> 单元/章节 -> 知识点。
- 每个知识点可挂接题目、参考答案、步骤模板。

增强（M2，预留）：
- 每个知识点可挂接多个视频解析资源。
- 视频资源包含：来源、版本、审核状态、时长、适用年级。

### 3.2 组卷与混排

- 组卷输入：年级、学科、考试类型（中考/高考/日常测）、题型、难度、知识点集合。
- 组卷来源：
  - 来源 A：知识点题库。
  - 来源 B：历史真题库。
- 混排策略：按比例抽取（例如 A:B=7:3），并在题型与难度维度上二次平衡。
- 年级适配：默认仅抽取“当前年级可用”题目；允许跨年级知识点但需显式开关。

### 3.3 随机规则定义器（可视化）

- 规则对象：规则模板（可复用）。
- 可视化配置维度：
  - 难度分布（易/中/难占比）。
  - 知识点覆盖率（必含/可选）。
  - 题型配比。
  - 历史真题占比。
  - 去重规则（同知识点、同年份、同来源）。
- 可视化能力：
  - 表单+预览（预计题量、难度分布、知识点命中率）。
  - 模板保存、发布、停用、版本回滚。

### 3.4 答案与大题步骤

- 客观题：标准答案 + 判分规则。
- 主观题/大题：
  - 参考答案。
  - 步骤化解题思路（步骤 1..N）。
  - 步骤可映射知识点与得分点。

### 3.5 视频解析（增强方案）

流程：
1. 输入题目、答案、步骤模板与知识点。
2. 系统半自动生成讲解脚本、字幕、配音与视频草稿。
3. 老师或管理员审核（通过/驳回/修改后通过）。
4. 审核通过后挂接到题目或知识点并对学生可见。

可用标准：
- 视频可播放、音画同步、字幕可读。
- 讲解步骤完整，且与题目答案一致。
- 知识点映射准确。
- 审核流程留痕（审核人、时间、版本）。

## 4. 数据与规则约束

- 题目必须至少关联 1 个知识点。
- 混排时若历史真题不足，需自动降级并提示缺口。
- 规则模板发布后对老师可见；下线模板不可新建使用，但历史试卷可追溯。
- 视频解析未审核通过时，仅管理员与审核人可见。

## 5. 人工验收标准

1. 能在客户端按知识路径查询图文内容，并看到知识点关联题目。
2. 能在老师端创建“知识点题+历史真题”混排试卷，且年级匹配正确。
3. 能在规则定义器中配置难度、知识点、题型、真题比例并预览结果。
4. 考试后可查看客观题答案及大题步骤化解析。
5. 视频解析可完成“生成草稿 -> 审核 -> 发布 -> 学生播放”全流程。

## 6. 风险与缓解

- 风险：历史真题元数据不完整导致混排准确率下降。
  - 缓解：补齐题目标签校验，缺失时禁止入库。
- 风险：半自动视频质量波动。
  - 缓解：使用标准脚本模板 + 人工审核门禁。
- 风险：规则模板过多导致治理困难。
  - 缓解：模板分层（系统模板/学校模板）+ 版本生命周期管理。

## 7. 不在本次范围

- 全自动无审核的视频发布。
- 个性化多语言视频生成。
- 防作弊与智能监考能力。
