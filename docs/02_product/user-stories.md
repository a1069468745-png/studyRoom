## 学生

- 作为学生，我希望能按单元、章节和知识点查询课程内容，这样我可以按当前教学进度学习。
- 作为学生，我希望能参加老师安排的考试，这样我可以完成练习和测验。
- 作为学生，我希望能查看自己的成绩、错题和分析，这样我可以知道薄弱点。
- 作为学生，我希望能看到自己的成绩趋势和知识点掌握情况，这样我可以判断自己的变化和薄弱点。
- 作为学生，我希望能看到题目的知识点关联和解析，这样我可以理解为什么错。
- 作为学生，我希望能观看已发布且授权的视频解析，这样我可以更直观地理解复杂题目的解法。

## 老师

- 作为老师，我希望导入题库并提交审核，这样我可以快速积累可用题目。
- 作为老师，我希望按年级、学科、教材版本、题型和难度组卷，这样我可以快速创建考试。
- 作为老师，我希望按指定单元、指定章节或课程范围组卷，这样我可以让试卷与当前教学进度一致。
- 作为老师，我希望指定学生参加考试，这样我可以组织班级测验。
- 作为老师，我希望查看自己班级的成绩分析，这样我可以判断学生掌握情况。
- 作为老师，我希望查看组卷结果统计预览，这样我可以在发布前确认题量、难度和覆盖范围是否合理。

## 管理员

- 作为管理员，我希望导入知识库内容，这样我可以维护课程体系。
- 作为管理员，我希望维护教材版本下的课程树结构，这样单元、章节和知识点能稳定表达教学范围。
- 作为管理员，我希望审核老师导入的题库，这样我可以保证题目质量。
- 作为管理员，我希望验证数据接入结果，这样我可以保证系统内容一致性。
- 作为管理员，我希望审核和发布视频解析草稿，这样学生只会看到通过审核的内容。

## 系统能力故事

- 作为系统，我希望把题目自动关联到知识点，这样题目、错题和知识库可以联动。
- 作为系统，我希望在批改后自动生成分析，这样老师和学生能快速获取反馈。
- 作为系统，我希望对理科客观题自动评分，这样可以减少人工成本。
- 作为系统，我希望把组卷范围保存为明确的单元、章节或课程树节点选择结果，这样考试范围可追溯且不歧义。
- 作为系统，我希望对题目支持视频草稿、审核发布和学生播放的最小闭环，这样复杂题可以更直观地解释解法。
