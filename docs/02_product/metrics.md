## 北极星指标

- 有效考试闭环数: 完成组卷、考试、批改、分析并归档的考试数量。

统计周期：按周统计、按月复盘。
数据采集方式：从组卷、考试、批改、分析、归档相关业务表和任务表聚合。

## 功能指标

### 知识库

- 知识点录入成功率：目标 >= 95%，按周统计，采集自知识点创建成功/失败日志。
- 知识点查询成功率：目标 >= 99%，按周统计，采集自知识点查询接口日志。
- 知识点跳转成功率：目标 >= 98%，按周统计，采集自课程树导航与知识点详情接口日志。

### 题库与导入

- 题库导入成功率：目标 >= 95%，按周统计，采集自题库导入任务日志。
- 导入审核通过率：观察指标，按周统计，采集自题库审核记录。
- 题目关联知识点覆盖率：目标 = 100%，按周统计，采集自题目与知识点映射数据。

### 考试与批改

- 考试创建成功率：目标 >= 95%，按周统计，采集自考试创建与组卷任务日志。
- 考试完成率：目标 >= 85%，按周统计，采集自考试实例与交卷记录。
- 自动批改覆盖率：目标 >= 90%（客观题范围内），按周统计，采集自批改记录。
- 自动批改准确率：目标 >= 95%（客观题范围内），按周统计，采集自自动批改与人工复核比对结果。

### 成绩分析

- 分析报告生成成功率：目标 >= 95%，按周统计，采集自分析任务日志。
- 班级/个人分析查看成功率：目标 >= 98%，按周统计，采集自分析查询接口日志。
- 错题本沉淀率：目标 >= 90%，按周统计，采集自错题记录与考试题目结果。
- 个人成绩趋势可见率：目标 >= 95%，按周统计，采集自成绩趋势接口日志。
- 知识点掌握率展示完成率：目标 >= 95%，按周统计，采集自分析结果数据完整性检查。

### 视频解析

- 视频草稿生成成功率：目标 >= 90%，按周统计，采集自视频生成任务日志。
- 视频审核发布成功率：目标 >= 95%，按周统计，采集自视频审核与发布记录。
- 学生视频播放成功率：目标 >= 95%，按周统计，采集自视频播放接口日志。

## 业务指标

- 老师从配置规则到出卷完成的平均耗时：目标 <= 10 分钟，按周统计，采集自组卷开始与成功时间。
- 学生完成一次考试后的分析可用率：目标 >= 95%，按周统计，采集自交卷与分析生成记录。
- 管理员完成一次知识库更新的平均耗时：目标 <= 30 分钟，按周统计，采集自知识库导入、审核与发布记录。
- 题目分析关联到知识点的覆盖率：目标 = 100%，按周统计，采集自题目、解析与知识点关联数据。
