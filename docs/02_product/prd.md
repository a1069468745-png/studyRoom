## 产品目标

构建一套面向学生、老师和管理员的内部知识库与考试系统，支持中学语数英数理化首版能力，完成内容录入、知识查询、组卷、考试组织、在线答题、自动批改、成绩分析、错题沉淀、历史真题管理和文档导出。

## 目标用户

- 学生: 自主学习、参加考试、查看自己的成绩和错题。
- 老师: 导入题库、组织考试、查看自己班级成绩、分析学生表现。
- 管理员: 管理知识库、审核题库导入、接入与验证数据、查看全部数据。

## 首版范围

### 必做

- 知识库
- 题库
- 组卷
- 考试组织
- 在线答题
- 自动批改
- 成绩分析
- 错题本
- 历史真题
- 导出
- 题目分析
- 知识点自动关联

### 增强能力

- 理科复杂题视频讲解

### 明确不做

- 智能老师对话
- 防作弊
- 多地区真题
- 小学课程
- 高中课程

## 核心流程

### 学生流程

1. 查询知识库。
2. 基于课程、知识点或错题学习。
3. 参加考试并完成答题。
4. 查看批改结果、错题与学习建议。

### 老师流程

1. 导入题库并提交管理员审核。
2. 组织考试计划，生成考试实例。
3. 指定人员参加考试。
4. 查看批改结果与学生成绩波动分析。
5. 导出试卷、答案、解析或分析报告。

### 管理员流程

1. 导入知识库内容。
2. 审核老师导入的题库内容。
3. 验证数据接入结果。
4. 管理题库、知识库、历史真题和考试配置。

## 功能需求

### 1. 知识库

- 支持按 `学段 -> 年级 -> 学科 -> 单元 -> 课 -> 知识点` 组织内容。
- 支持多渠道录入，至少支持文本和图片。
- 支持查询、查看、编辑、增删改查。
- 支持知识点之间的跳转和关联。

### 2. 题库

- 支持老师导入题目，管理员审核后生效。
- 支持按年级、学科、教材版本、题型、难度管理题目。
- 支持题目关联知识点。
- 支持题目分析，输出解题思路、结果和知识点映射。

### 3. 组卷与考试组织

- 支持考试计划。
- 支持考试时间变更。
- 支持补考。
- 支持指定人员参加考试。
- 支持按年级、学科、教材版本、题型、难度、数量组卷。
- 支持中考随机模拟。
- 支持历史真题与随机混出。
- 考试控制项至少包括开始时间、结束时间、考试时长、迟到处理、自动交卷。

### 4. 在线答题与批改

- 支持在线作答。
- 支持收卷后自动批改。
- 理科客观题尽量全自动。
- 文科主观题支持半自动或人工。
- 批改结果能返回每题分数和总分。

### 5. 成绩分析与错题本

- 支持学生、班级、级部、课、知识点等多维分析。
- 支持班级平均分、课平均分、级部维度、个人趋势、知识点掌握率、错题聚类、题目得分分布。
- 支持环比和多维度对比。
- 个人级别分析至少支持单科班级级部排名、个人历史环比、平均分、个人趋势、级部维度、知识点掌握率、错题等。
- 支持错题本查询、查看答案分析、增删改查。

### 6. 历史真题

- 首版覆盖山东省内。
- 中考全量覆盖。
- 支持期中、期末和单元测。
- 年份从 2000 年以后开始。

### 7. 导出

- 需求中涉及导出的内容都要支持导出。
- 支持导出试卷、答案、解析和分析报告。
- 首版优先支持 Word、PDF，图片最后。

### 8. 题目分析

- 支持单题解析。
- 输出解题思路、结果和对应知识点。
- 理科复杂题支持视频讲解，视频需要围绕当前题目的解法生成短视频，输出为 720P，时长最大上限 1 分钟，且要讲清题目。

## 非功能需求

- 支持本地化部署。
- 数据本地存储。
- 第三方模型可配置接入。
- 支持多角色权限控制。

## 报告模板

- 首版支持自定义报告模板。
- 默认提供基础报告模板和使用指导。

## 不做事项

- 不做智能老师对话。
- 不做防作弊。
- 不做多地区真题首版覆盖。
- 不做小学和高中课程首版覆盖。

## 待确认事项

- 内容来源的合法性与审核标准。
- 试卷混卷规则和题型比例。
- 视频讲解的存储与生成方式。
- 批改半自动流程的人工确认节点。
- 分析报告的固定模板。
