## 产品目标

构建面向学生、老师、管理员的知识库与考试系统，支持图文知识学习、规则化组卷、考试作答、答案解析和视频讲解能力。

## 角色与端

- Web 客户端：老师、学生。
- 管理端：管理员。

## 功能范围

### 1. 知识库

- 首版支持图文内容管理与查询。
- 内容结构支持：学段 -> 年级 -> 学科 -> 章节 -> 知识点。
- 每个知识点可关联题目、答案、步骤模板。
- 预留视频资源字段，支持后续接入视频解析。

### 2. 双端功能规划

Web 客户端：
- 学生：学习知识点、参加考试、查看答案/解析/步骤、观看审核通过的视频解析。
- 老师：配置组卷条件、使用规则模板生成试卷、查看成绩分析。

管理端：
- 管理员：知识库治理、题库审核、规则模板发布管理、视频解析审核发布、基础配置维护。

### 3. 组卷与混排

- 支持从知识点题库中生成试卷。
- 支持混合历史真题。
- 支持中考/高考混排。
- 默认匹配当前年级，支持跨年级知识点开关。
- 支持全年级知识点范围选择。

### 4. 随机规则定义器

- 支持可视化配置规则。
- 支持多维度：难度、知识点覆盖、题型、历史真题比例、去重约束。
- 支持模板保存、发布、停用、版本管理与回滚。

### 5. 答案与解析

- 客观题支持标准答案与自动判分。
- 大题支持参考答案。
- 大题支持步骤化解题思路。
- 步骤可关联知识点和得分点。

### 6. 视频解析（增强方案）

- 支持半自动生成：脚本草稿、字幕、配音、视频草稿。
- 必须人工审核后发布。
- 输出建议：720P，1-3 分钟讲解短视频。

## 非目标

- 无审核的全自动视频发布。
- 个性化多语言视频生成。
- 防作弊与智能监考。
