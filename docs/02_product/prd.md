## 产品目标

构建面向学生、老师、管理员的知识库与考试系统，支持图文知识学习、规则化组卷、考试作答、答案解析和视频解析能力。

## 角色与端

- Web 客户端：老师、学生。
- 管理端：管理员。

## 功能范围

### 1. 知识库

- 首版支持图文内容管理与查询。
- 内容结构支持教材版本下的课程树，默认结构为：学段 -> 年级 -> 学科 -> 单元 -> 章节 -> 知识点。
- 课程树节点需支持排序，用于表达教学进度和考试覆盖范围。
- 每个知识点可关联题目、答案、步骤模板。
- 预留视频资源字段，支持后续接入视频解析。

### 2. 双端功能规划

Web 客户端：
- 学生：学习知识点、参加考试、查看答案/解析/步骤、观看已发布且授权的视频解析。
- 老师：配置组卷条件、使用规则模板生成试卷、查看本教学范围内的成绩分析。

管理端：
- 管理员：知识库治理、题库审核、规则模板发布管理、视频草稿生成任务管理、视频解析审核发布、基础配置维护。

### 3. 组卷与混排

- 支持从知识点题库中生成试卷。
- 支持混合历史真题。
- 支持中考/高考混排。
- 默认匹配当前年级，支持跨年级知识点开关。
- 支持全年级知识点范围选择。
- 支持按指定单元出题。
- 支持按指定章节出题。
- 支持按课程树范围出题，例如“从第 1 单元到第 5 单元”或“选择单元 2 下的第 1 章到第 3 章”。
- 历史真题不足时自动降级并明确提示缺口。

### 4. 随机规则定义器

- 支持可视化配置规则。
- 支持多维度：难度、知识点覆盖、题型、历史真题比例、去重约束、课程范围。
- 支持模板保存、预览、发布、停用、版本管理与回滚。

### 5. 答案与解析

- 客观题支持标准答案与自动判分。
- 大题支持参考答案。
- 大题支持步骤化解题思路。
- 步骤可关联知识点和得分点。

### 6. 视频解析（首版最小验收）

- 支持基于题目、答案、步骤生成视频草稿。
- 视频草稿必须人工审核后发布。
- 学生端仅可观看已发布且授权的视频解析。
- 首版不以字幕、配音、720P、时长为强制验收门槛。

### 7. 数据与规则约束（决策落地）

- 题目必须至少关联 1 个知识点，不满足不允许入库。
- 题目默认通过知识点关联到单元/章节；必要时可冗余记录课程树节点以支持按单元快速筛题。
- 历史真题不足时，混排必须自动降级并明确提示缺口。
- 规则模板发布后老师可见；下线后不可新建使用，但历史试卷必须可追溯。
- 视频解析未审核通过时，仅管理员与审核人可见。
- 老师仅可访问其教学授权范围内的题库、模板、考试和分析数据。
- 学生仅可访问自己的考试、成绩、学习内容和被授权的视频解析。
- 组卷范围必须保存为明确的单元、章节或课程树节点范围，不引入百分比类规则。

## 非目标

- 无审核的全自动视频发布。
- 首版不要求字幕、配音与 720P 质量门槛。
- 个性化多语言视频生成。
- 防作弊与智能监考。
