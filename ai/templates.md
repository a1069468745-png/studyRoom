# templates.md

## 1. 使用规则

Agent 生成或更新项目文档时，必须优先使用本文件中的模板。

如果模板中某项信息未知，必须填写 `TODO`，不得编造。

如果模板不适合当前任务，Agent 可以提出修改建议，但不得私自更换文档结构。

所有文档必须保留以下信息：

- 文档名称
- 当前阶段
- 状态
- 最后更新日期
- 相关来源
- TODO 项
- 风险或假设

---

# 2. 通用文档头模板

所有项目文档建议使用以下头部：

```md
# 文档标题

## 文档信息

| 字段 | 内容 |
|---|---|
| 项目 | TODO |
| 阶段 | TODO |
| 状态 | 草稿 / 待确认 / 已确认 / 已废弃 |
| 版本 | v0.1 |
| 最后更新 | TODO |
| 负责人 | TODO |
| 相关文档 | TODO |
```

# 3. 通用 TODO 模板
```md
## TODO

| ID | 问题 | 类型 | 优先级 | 负责人 | 状态 |
|---|---|---|---|---|---|
| TODO-001 |  | 需求/产品/技术/测试/安全 | P0/P1/P2 |  | 未处理 |
```
